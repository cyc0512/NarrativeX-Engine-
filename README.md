# ⚙️ NarrativeX Engine

**NarrativeX Engine** 是一款基于 C++17 和 Qt5 开发的文字交互底层引擎。

本项目旨在解决传统视觉小说（Visual Novel）中“固定选项导致交互死板”与“大模型自由生成导致剧情暴走”的行业痛点。引擎提供了一套**“本地状态机 + 大模型语义识别”**的混合架构，开发者在无需掌握 C++ 网络并发技术的前提下，只需配置 JSON 剧本与外部提示词文件，即可构建具备动态情绪反馈及主线收束能力的文字交互体验。

## 💡 品类定义 (Category Definition)
现有文字游戏要么局限于被动选择，要么沦为漫无目的的 AI 聊天机器人。**NarrativeX** 提出并实践了一种名为 **FluidStory（流态故事）** 的全新细分玩法。
区别于传统视觉小说的“读”与现有 AI 角色的“聊”，FluidStory 让玩家可以像和真人聊天一样，用自然语言肆意试探 NPC 的底线；而引擎底层的状态机与主线收束机制，会将每一次对话的涟漪，最终引向一个不可逆转的既定结局。

## 🎮 引擎核心能力 (Engine Capabilities)

1. **语义级自由交互**：支持玩家自然语言输入，调用 LLM 进行意图识别与回复生成，打破固定选项桎梏。
2. **动态状态注入**：同一 NPC 在不同剧情节点（如：初识、怀疑、黑化）拥有不同的精神状态。引擎提取节点状态动态生成 Prompt，使 NPC 反应具备连续性与成长性。
3. **主线收束与危险域拦截**：当玩家的自由输入触及系统设定的底线时，语义识别模块将强制中断常规逻辑，收束至预设的隐藏结局。
4. **底层配置解耦**：剧情由 `story.json` 驱动，角色人设由外部提示词驱动，**无需修改 C++ 代码即可更换整个游戏剧本与角色**。

## 🕹️ 附带游戏实例：FluidStory
本仓库包含了一款名为 **《FluidStory》** 的示例游戏（基于高中校园背景的心理悬疑与恋爱叙事）。您可以通过运行本项目，直接体验这种结合了自然语言输入的新型交互模式，并参考其配置方式，快速构建您自己的 AI 文字游戏。

## 🛠️ 技术栈 (Tech Stack)
- **核心语言**: C++17
- **界面框架**: Qt5 (GUI 渲染与多线程异步通信)
- **网络通信**: libcurl (调用大模型 API)
- **数据库**: SQLite3 (存档、状态持久化与自动迁移)
- **数据格式**: nlohmann/json (剧本与状态序列化)
