# 🌸 Isolate Engine (基于大模型的文字交互引擎)

**Isolate Engine** 是一款基于 C++17 和 Qt5 开发的文字交互引擎。本项目旨在探索大语言模型（LLM）在文字游戏中的落地方式，将**传统本地状态机 (FSM)** 与**云端大模型**结合，解决传统 Galgame 中固定选项导致的交互死板问题。

开发者可以通过修改 JSON 剧本和提示词，快速构建具备基础情绪反馈和语义识别的游戏原型。

## 🎮 核心功能 (Implemented Features)

1. **自由文本输入解析**：保留传统选项的同时，提供自由输入框。玩家输入的文本将发送给大模型，模型会根据设定的人设返回符合语境的回复。
2. **多线程异步网络通信**：使用 `QtConcurrent` 将大模型 API 请求移至后台线程，防止网络延迟导致的 UI 界面卡死。
3. **数据驱动的本地状态机**：剧情节点、选项跳转、好感度变化全部由外部的 `story.json` 文件驱动。
4. **多存档位与数据库持久化**：使用 SQLite 记录玩家进度与好感度，支持多槽位读档、删档，并实现了数据库表结构的自动迁移。

## 🏗️ 架构设计记录（开发中 / 未完成）

以下为引擎后续的开发规划与架构思路，目前正在逐步实现：

*   **状态注入 (State Injection)**：【开发中】计划在 JSON 节点中定义 NPC 的当前精神状态，在请求 AI 时动态拼接进 Prompt，使 NPC 在不同剧情阶段对同一句话产生不同的反应。
*   **主线收束机制 (Mainline Convergence)**：【设计阶段】为解决 AI 自由回复导致剧情暴走的问题，计划通过 AI 语义识别玩家的危险行为（如“试图离开”），触发引擎底层逻辑，强制将剧情导向预设的坏结局，保证故事的完整性。

## 🛠️ 技术栈 (Tech Stack)
- **核心语言**: C++17
- **界面框架**: Qt5
- **网络通信**: libcurl (HTTP 请求)
- **数据库**: SQLite3
- **数据解析**: nlohmann/json
